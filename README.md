## ASP Product Catalog
Simple ASP.NET Core application for displaying and creating products using the MVC model. 

### Explanation 
This application uses ASP.NET Core with the MVC model to create a product catalog application which allows users to view and add products. 
It has three pages: Index which displays all products, details which displays details of a specific product, and create which allows
users to add products. It uses a controller called `ProductsController` to route website actions across the pages and uses strongly
typed views to manage product data efficiently.
